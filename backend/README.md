# Backend — XYZ Auto Service

Ứng dụng Java 21 / Spring Boot, quản lý lịch hẹn và REST API với H2 (demo) hoặc PostgreSQL (triển khai theo đề bài).

Chạy Windows: `run-dev.cmd` hoặc `docker compose up -d` sau đó `run-postgres.cmd`.

Phải giữ thư mục `frontend/` ngang cấp với `backend/`: Maven tự sao chép frontend vào `target/classes/static/` khi build. Đọc `../README.md` trước khi triển khai.
