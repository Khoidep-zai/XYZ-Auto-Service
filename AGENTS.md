## Agent skills

### Issue tracker

Issues live as Markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage role names. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout. See `docs/agents/domain.md`.

### Spec-driven work

For features and changes with meaningful behavioral or architectural impact, follow
`docs/agents/spec-kit.md` and the project constitution in
`.specify/memory/constitution.md`. Keep feature artifacts under `.scratch/<feature>/`.
For small fixes, use a proportionate investigation and verification instead.

When `.codegraph/` exists, use CodeGraph before searching or reading indexed code.
