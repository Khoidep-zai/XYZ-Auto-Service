# Frontend — XYZ Auto Service

- `index.html`: giao diện và logic hiển thị ban đầu.
- `app.js`: kết nối API Spring Boot theo đường dẫn `/api/**`.
- `workshop.css`: CSS đã tạo sẵn để demo.
- `tailwind.input.css`, `tailwind.config.cjs`: tùy chọn cho việc phát triển giao diện.
- `vendor/`: CSS/fonts từ Font Awesome.

**Không mở `index.html` bằng file://** để trình diễn đặt lịch. Hãy khởi chạy backend (xem README ở thư mục gốc) rồi truy cập http://localhost:8080 để frontend và API chạy cùng địa chỉ.
